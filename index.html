Smart Payment

Transformación Tecnológica de una Plataforma Empresarial de Pagos

Contexto y Descripción

Smart Payment era una plataforma de procesamiento de pagos con una arquitectura basada en Web Services SOAP que presentaba limitaciones de escalabilidad, pérdida de transacciones y altos costos de mantenimiento. La compañía necesitaba una modernización urgente para garantizar estabilidad, trazabilidad y capacidad de crecimiento sin afectar la operación.

Mi Rol

Lead Software Developer | Technical Leader | Full Stack Developer

Lideré un equipo de cinco desarrolladores, coordinando la planificación técnica, la distribución de tareas y la adopción de estándares. Participé activamente en el diseño de la arquitectura, desarrollo de backend/frontend y optimización de base de datos.

Solución y Arquitectura

Se diseñó una arquitectura por capas basada en servicios para desacoplar componentes críticos y sustituir Web Services por APIs REST.

  • Backend: C#, ASP.NET Core (.NET 6).
  • Frontend: Angular, TypeScript, HTML5, CSS3.
  • Base de Datos: SQL Server, Stored Procedures, optimización de consultas.
  • DevOps & Integraciones: Azure DevOps, CI/CD, REST APIs, procesos de certificación PSI.

Principales Logros

  • Migración exitosa y progresiva de SOAP a REST en una operación crítica en vivo.
  • Eliminación de pérdida de transacciones mediante mecanismos de validación.
  • Modernización del portal administrativo con Angular mejorando usabilidad y rendimiento.
  • Automatización de despliegues (CI/CD) y estandarización de revisiones de código.

Lo más desafiante

El principal reto fue ejecutar una modernización tecnológica sobre una plataforma que procesaba operaciones críticas, garantizando la continuidad del servicio mientras se reemplazaban gradualmente componentes heredados sin interrumpir el flujo de pagos.

Mi Rol

GuardPay

Plataforma FinTech Inteligente para Pagos Digitales en Latinoamérica

Descripción

GuardPay es una plataforma FinTech empresarial diseñada para centralizar operaciones de Pay In y Pay Out en múltiples países de Latinoamérica. La solución integra proveedores financieros, automatiza procesos de conciliación y ofrece una arquitectura escalable preparada para incorporar nuevos métodos de pago, entidades bancarias y mercados internacionales.

Además del desarrollo tradicional, durante el ciclo de vida del proyecto se incorporaron herramientas de Inteligencia Artificial para acelerar el diseño técnico, optimizar procesos de desarrollo y fortalecer la documentación de la solución.

Mi Rol

Software Architect | Senior Full Stack Developer | AI-Assisted Software Engineer

  • Diseño de la arquitectura de software y modelo de datos.
  • Desarrollo de APIs REST y del portal administrativo.
  • Optimización de consultas SQL e integración con proveedores financieros.
  • Automatización de procesos de conciliación.
  • Uso de IA para acelerar el análisis, generación de documentación técnica y validación de soluciones técnicas.

Arquitectura y Tecnologías

Diseñada bajo una arquitectura modular y orientada a servicios, desacoplando la lógica de negocio de las integraciones financieras.

  • Backend: C#, .NET 9, ASP.NET Core, Entity Framework, Dapper.
  • Frontend: Angular, TypeScript, Bootstrap, PrimeNG.
  • Base de Datos: SQL Server, Stored Procedures, Triggers.
  • IA: ChatGPT, Claude, Google Gemini, GitHub Copilot.

Resultados

  • Plataforma preparada para operar en múltiples países de Latinoamérica.
  • Arquitectura modular que simplifica la incorporación de nuevos proveedores de pago.
  • Automatización de procesos de conciliación y liquidación.
  • Reducción del tiempo de desarrollo mediante el uso estratégico de herramientas de IA.

Inteligencia Artificial Aplicada

Como parte de la evolución de GuardPay, se incorporaron capacidades de Inteligencia Artificial para mejorar el análisis operativo y la toma de decisiones en tiempo real. Entre las funcionalidades implementadas se incluyen:

  • Reportes en lenguaje natural: Consultas operativas como "¿Cuál fue el volumen de Pay In en Argentina hoy?".
  • Dashboards dinámicos: Gráficos que se adaptan al contexto de la consulta.
  • Análisis de tendencias: Identificación de variaciones en volumen y métodos de pago.
  • Resúmenes ejecutivos: Métricas clave e incidencias automáticas.
  • Asistencia inteligente: Reducción del tiempo para obtener información crítica.
  • Arquitectura AI-Ready: Preparada para modelos predictivos y detección de anomalías.
